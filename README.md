# 预设条目对比、编辑与拖拽迁移

## 2.0.0

- 旧版栏新增“酒馆预设”按钮，尝试读取当前酒馆已加载的 OpenAI 预设缓存；仍保留文件导入。
- 新增 IndexedDB 项目保存区，可创建、覆盖保存、加载和删除项目。项目包含两份完整预设、拖拽记录、手动修改记录和筛选状态。
- 新增撤回，支持撤回最近的条目拖拽、覆盖和手动内容修改，最多保留 50 步。
- 新增“已拖拽”和“已手动修改”筛选。
- “保存修改”覆盖当前项目快照；未创建项目时会先要求命名。

注意：不同 SillyTavern 版本暴露预设缓存的方式不同。若“酒馆预设”提示未找到，请使用保留的 JSON 文件导入功能。
